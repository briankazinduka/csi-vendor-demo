# CSI Vendor Directory — Public Demo

Public, static demo of the **NEU CSI Vendor Directory** used to test embedding
in WordPress (sites.northeastern.edu) via an `<iframe>`.

⚠️ **Fake sample data only.** `vendors.json` here contains placeholder vendors
with `@example.com` contacts — no real vendor contact information. Real data
lives on NEU's WordPress in production.

- `index.html` — the single-file dashboard (HTML + CSS + vanilla JS)
- `vendors.json` — fake sample data the page fetches
